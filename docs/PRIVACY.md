# 隐私与权限说明

LitScout Download 0.1.2 没有开发者遥测或自动云端同步。清单、日志、PDF、分页文本和配对信息保存在用户本机。Agent 能读取核验后的论文和导出路径，因此用户也应了解所使用的 Agent 平台如何处理输入。

提供公开 PDF 直链时，插件先向该链接发起不带 Cookie、不跟随重定向的请求；失败后在用户浏览器中打开来源页面。来源站点会收到这些正常访问请求。插件不将论文清单发送到 LitScout 云端。

自动安装助手首次运行会从主机配置的 Python 包源下载依赖，不向 LitScout 云端发送清单。服务地址保存在本机 client.json；安装日志、后台服务日志和更新前的 Skill/插件备份也保存在本机。配对码由 Agent 返回给用户，短期有效，不能与长期 Agent 令牌混用。

插件访问清单中的出版社/仓储，使用用户当前浏览器会话。登录由用户在出版社页面完成，插件不向本机服务上传 Cookie 或密码。本机回环连接使用单独随机令牌，用户不应把服务代理到公网。

浏览器权限用途：

| 权限 | 用途 |
| --- | --- |
| `debugger` | 在绑定的论文标签页监听 PDF 网络响应、分段内容和下载；浏览器可能显示调试提示 |
| `scripting`、`tabs` | 识别论文 PDF 入口，打开/恢复论文标签页；只在任务相关页面注入探测脚本 |
| `downloads` | 关联当前任务的保存事件，文件写入完成后尝试回传 |
| `storage`、`unlimitedStorage` | 保存配对、状态和受预算限制的临时 PDF 缓存 |
| `sidePanel` | 右侧任务与人工处理界面 |
| `notifications`、`alarms` | 接单/人工待办提醒和后台轮询 |
| `https://*/*` | 出版社、OA 仓储及其不同下载域名；不会预先确定所有出版社域名 |
| `http://127.0.0.1/*` | 与用户指定端口的本机服务通信 |

这些权限技术上授予较广泛的浏览器访问能力，商城审核需要逐项说明，不能把实现上的使用范围等同于浏览器权限本身已被收窄。

插件不把正文上传到 LitScout 官网。左上官网链接由用户点击后打开 `https://litscout.zeabur.app/`，不携带清单、ID 或令牌。

自动回传只读取配置下载目录下的 PDF。用户手动导入的 PDF 也会交给本机解析器。下载内容可能受出版社许可限制，应仅用于自己有权使用的研究活动；开源代码许可不授予论文再分发权。

记录不会自动过期。卸载扩展不删除本机服务数据或已导出论文。若需清理，应先停服并备份，再由用户针对 `.litscout-download` 和指定导出目录处理；本项目不会自动删除其他 LitScout 实例的数据。
