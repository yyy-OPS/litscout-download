# 0.1.1 自动配置方案

用户安装了浏览器扩展后，Agent 运行 Skill 的 `scripts/setup.py`，负责安装、后台启动、健康检查和生成配对码。已有权限明确的安装请求内，不把 Python、端口或令牌配置步骤转交用户。

安装采用当前用户专用目录和 Python venv。默认端口 57133，默认数据目录 `.litscout-download`。0.1.2 起允许任意 1024–65535 范围内的端口，不复用旧 `.litscout-fulltext` 数据目录；其他程序占用端口时报告冲突，不结束其进程。客户端从本机 client.json 读取地址，新插件可从连接码自动解析端口。

Skill Release 自带经 SHA-256 校验的 companion.zip，只含公开下载服务和插件。源码安装使用 `python scripts/install.py`，同时安装 Skill、准备稳定的插件目录并启动服务。不能静默启用未上架浏览器扩展；首次用户仍需在扩展管理页开启开发者模式并加载目录。已经启用插件的用户只粘贴 code 即可。

安装器重复运行复用经过本机令牌验证的服务，不杀进程、不换令牌、不删除配对。安装操作受 OS 文件锁保护。变更 Skill 或插件文件前保留备份；Python 环境按版本和内容哈希隔离。服务后台运行，日志保存在数据目录，不设置系统环境变量或开机启动项。

配对码有效 300 秒，只使用一次。安装器输出 JSON 包括服务地址、code、含端口的 connectionCode、插件路径和已配对数量；不输出 Agent 令牌。首次依赖安装需要网络，完成后下载功能不依赖 LitScout 云端。

验证范围：新目录安装、启动和真实配对；重复安装复用服务；禁止旧端口和旧目录；端口冲突不改变原服务；校验损坏安装包；单独 Skill ZIP 在没有源码目录时完成配置；完整下载回归。更新原下载版 Skill 属于本次授权，旧发现版和旧全文版继续保留。
